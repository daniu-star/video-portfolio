# V28 三维真实感增量说明

## 更新范围

本版以 V27 的全部文件为基础，保留数据库、原始高程采样、原始道路与配置。改造集中于渲染引擎，避免再重写游戏任务或篡改地形数据。

- `assets/js/scene/webgl-terrain-v25.js`：WebGL2 高度场采用双三次插值、分层网格、重新计算的表面法线、岩石/草地/林地材质、近景细节、方向光、简化环境遮蔽和空气透视。均衡/精细档位按照高程源密度采样，支持32位顶点索引。
- `assets/js/scene/engine.js`：保留稳定的 Canvas2D 地形绘制路径，适度增加细分预算并减少远景蒙雾。WebGL2 创建失败时仍可操作地图。
- `assets/js/scene/v28-quality-ui.js` 与 `assets/css/v28-geology.css`：显示实际采用的渲染路径和高程来源，可手动调整地形精细度。
- WebGL2 地形与水面统一使用相机焦距，减少驾驶或乘船镜头下的两层投影错位。

## 重要限制

当前 `assets/data/real_elevation.js` 仍为空白占位。原始概念高程（FAST 5329 个采样、花江 4761 个采样）未变。高密度网格只是对现有采样进行插值和有界视觉微扰，不能增加真实地形测量精度。导入可用的DEM后，视觉微扰自动关闭。

此处的自然地表材质、定向光与河流波纹属于视觉近似。没有高精度影像、实测岸线、建筑BIM、桥梁CAD、船舶模型或经过验证的水动力学。请勿将画面用于测绘、航行或工程设计。

## 验收情况

2026-10-28 本地 Chromium 无法建立 WebGL2 上下文。因此 WebGL2 源码已通过 JavaScript 语法与静态结构检查，但**没有 GPU shader 编译、画面或性能验收**，交付的是增量测试版本。Canvas2D 兼容路径已在 1280×800 和 390×844 浏览器检查，可操作画质按钮和切换天眼/花江。游船与过桥的入口、视角和退出流程已通过离线内联浏览器检查，测试中未捕获脚本异常。

GPU 实机验收应检查 WebGL2 shader 的编译日志、实际网格与河流深度遮挡、驾驶舱与场景相机校准、连续运行30分钟、帧时间P95、显存和设备兼容，并与 V27 相同镜头进行定点对照。实际地形升级应优先完成 DEM 数据获取、地理坐标配准和来源审查，再导入专业建模流程。
