## 2. 功能路径

1. 推荐以 `run_windows.bat` / `run_mac_linux.sh` 启动 HTTP 服务，也可直接打开 `index.html` 运行离线模拟游戏。
2. 点击「进入3D地图」，顶部场景选择器切换到「中国天眼 FAST + 天文小镇」。
3. 点击金色的「启动天眼信号守护挑战」或地图内跟随台址的「◎ 启动天眼科普游戏」。
4. 进入游戏后点击「开始信号守护任务」，分别完成：
   - 排查三个虚拟发射源；
   - 回答三道 5/10/30 公里宁静区法规情境；
   - 从三条合成波形中识别应继续验证的候选脉冲模式。
5. 成功后获取「宁静守护者」完成卡，并可重新挑战或返回地图；Esc 随时退出。

## 3. 科学事实与示意内容严格分离

**真实、来源支持的规则：** 贵州省 2019 年第188号《贵州省500米口径球面射电望远镜电磁波宁静区保护办法》将 FAST 周边按核心区半径 5 公里、5—10 公里中间区、10—30 公里边远区划定，核心区对未经允许携带无线电发射设备等行为有具体限制。其余地区仍有差异化管理条件，不能理解为全部禁止或全部开放。

**教学合成：** 背景同心圆、三处“发射源”、虚拟噪声棒图、三张 SVG 波形、案例距台址 3/8/22 公里、任务重试次数都是教学/游戏表示，不是监测结果、审批意见、建筑实际位置或可供科研分析的数据。

游戏原文直接提供外部来源链接：
- 2025-02-26 全国网络普法报道（转引新华网）：https://www.cac.gov.cn/2025-02/26/c_1742272852825362.htm
- 贵州省人民政府令第188号（条文转载）：https://www.zgzfcbp.cn/zffile/show-135008.html

不可借此游戏推断 FAST 科研核心区的可进入性、真实射电干扰值、天文发现或个人行动许可。
