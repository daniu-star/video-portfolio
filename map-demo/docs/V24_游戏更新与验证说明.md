# V24 花江/天眼地形与游戏更新说明

## 项目结构

以 V23 原始 ZIP 的 `Map demo/` 作为基础。保留原工程数据库、配置、地形、脚本、图片、文档和启动文件；主动移除旧像素货车游戏的运行入口，其脚本移至 `docs/legacy/pixel-truck-v23-retired.js` 备查，数据文件保持原样。

## 地形升级

- 根据每处地形网格自身的最小最大高程计算受光和色阶，避免旧公式在较高山体上的颜色饱和。
- 增加陡坡岩石色调与相对等高线，让山脊与谷底层次更清楚；按画质限制绘制预算，避免高频多边形重绘。
- 改造 `assets/js/geo/offline-terrain.js` 支持可变网格大小的外部DEM采样。新下载工具、数据状态与出处详见 `DEM_真实高程集成说明.md`。
- 注意目前仍是原始模拟高程；真实DEM在当前环境没有实际下载，无法宣称真实地形完成。

## 花江桥梁五个工程观察节点

1. 桥面距水面625米如何理解。
2. 1420米主跨与2890米全桥如何区分。
3. 悬索桥吊索、主缆、主塔和锚碇的传力路径。
4. 施工过程的温度、索力和位移监测。
5. 干线交通改善与两岸村寨接驳的差异。

继续使用可收起非模态任务卡，玩家必须实际切换指定视角，回答后才能推进下一站。任务知识点有公开工程资料依据，不把场景当作精确结构测量或导航。

## 新游戏《贵州工程调查局》

替换旧像素货车；三份逐步解锁的调查档案分别为“为什么都建在山里”“靠什么工作”“周边生活如何变化”。每章四条证据任选两条，核验后展示完整的原因解释。调查结论保存在浏览器本地，并可清空。玩家操作不会改变工程历史。

`assets/js/ux/casebook-game.js`、`assets/css/v24-terrain-bridge-casebook.css` 为新游戏的主要代码。旧道路数据和开放路网导入模块没有删除，仍可在总览地图使用。

## 验收证据与限制

- JS 语法校验、入口文件与资源路径检查通过。
- 新游戏使用隔离浏览器测试，1280与390视口均三章通关，控制台未捕获脚本异常，没有横向溢出。
- 完整页面图形回归测试受当前环境浏览器导航限制和高负载Canvas性能影响，未完成全部完整流程验收。桥梁五关的逻辑进行了静态核查，仍需真实玩家连续体验验证。
- 游戏建模遵循英雄对象突出、交互路径清晰、遮挡控制等关卡空间设计规范；没有调用付费Meshy生成，也没有通过 Blender 几何检查、GPU性能测试和精密建模验收。
