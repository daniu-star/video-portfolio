# V25 双地点调查交互修复与山体电影化优化报告

## 实际修复

### 双地点调查游戏

调查弹窗位于 `.chrome` 容器内。该容器设置 `pointer-events:none` 以保障底图可拖动，但调查弹窗没有显式恢复事件接收，导致可见而不可点击。V25 在 `v25-interaction-cinema.css` 为 `#casebookGame` 及其按钮恢复 `pointer-events:auto`，保留地图原有拖动机制。

去除了 `regional-expedition.js` 与 `casebook-game.js` 对 `pixelGameLaunch` 的重复监听。调查游戏打开时将内部滚动位置归零，选择证据卡后恢复键盘焦点，并保留返回地图的操作路径。通过点击第一、第二张证据并验证提交，三个调查章节均可连续推进。

### 左上角地图选择器

原生 `select` 使用了透明按钮的视觉样式，在不同系统中可能形成黑底黑字。V25 明确设置背景、文字、选项、聚焦边框和手机端宽度，同时保留原有 `fast`、`huajiang`、`overview` 三个场景与选择功能。

### 地形电影化

增加“山川电影”主题，采用暖色天空光照、方向性山体阴影、岩壁坡度分层、局部山脊阴影与更清晰的地形明暗。新增独立 `webgl-terrain-v25.js`，在支持 WebGL2 的浏览器中可用深度测试的网格地形绘制现有采样场。在不支持 WebGL2 的环境里仍自动使用 Canvas2D。原有地理数据没有被修改，也没有新增未经核实的实测高程。

增加“电影观景 / 退出观景”按钮，收起覆盖画面的面板，调整天眼和花江大桥的镜头位置。观察模式可随时退出，恢复原地图资料与操作入口。使用更节制的重绘节奏，降低连续多边形绘制带来的 CPU 压力。

## 完整工程结构及主要修改

- `index.html` 增加 WebGL 地形层画布、电影观景入口与新样式、新脚本的挂载。
- `assets/css/v25-interaction-cinema.css` 新增交互修复和主题样式。
- `assets/js/scene/webgl-terrain-v25.js` 新增可选 WebGL2 地形着色器、网格构建及兼容回退。
- `assets/js/scene/engine.js` 增强 Canvas 坡地阴影、光照以及可选 WebGL2 场景绘制。
- `assets/js/app.js` 新增观景镜头、按钮及返回机制。
- `assets/js/ux/casebook-game.js` 增强证据点击焦点与打开时的状态恢复。
- `assets/js/ux/regional-expedition.js` 移除双重监听。
- `assets/js/db.js`、`assets/js/state.js` 增加山川电影主题定义。
- `config/cinematic_v25.json` 记录渲染条件与事实边界。

原始 `database/spatial_demo.db`、`assets/data/database.bundle.js`、`assets/data/real_elevation.js`、离线路网、地理锚点及 V24 既有配置保持不变。

## 后续专业建模的必要输入

要达到严格的写实地形，应为两处场景提供具有坐标系、分辨率、获取日期与许可说明的真实 DEM，并对天眼500米反射面及花江大桥的主塔、主缆、桥面采用来源可靠的工程构件模型。引入 PBR 材质、阴影贴图、地形LOD和可测试的碰撞层后，还需在目标设备上对显存、帧率、深度正确性和界面无遮挡开展专项验收。

《build-3d-game-rooms》的高精度资产建模、Blender 审查、付费 Meshy 生成及最终 Runtime Gate 在本轮没有执行或取得批准。工程中不含未经批准的第三方付费生成资产。
