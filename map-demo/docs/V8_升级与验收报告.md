# 贵州双工程 V8 · 公开高程、车辆、中文界面与空间科普升级说明

## 0. 交付基础及诚实边界

本版本直接基于用户旅程审计修复版工程继续修改，保留数据库、两大场景、建筑点击、地点影像入口和已有地图交互。**当前包并未内置真实贵州 DEM**，原因是本次构建容器不能与公开服务器建立连接。任何浏览器截图都不是“真实地形加载成功”的证明；截图展示的是程序化场景和新玩法。实际 DEM 下载、地图构件重新配准与真实道路测绘仍属后续任务。

## 1. 开源地形通路

- `tools/下载并构建真实地形.py`：从 AWS Open Data 免密钥下载 Terrarium 瓦片，基于两个公开坐标锚点做地形网格重采样，生成 JS 离线高程包；原始瓦片保留 URL 和 SHA-256。
- `assets/js/geo/offline-terrain.js`：对离线包的采样点数、结构和值范围进行完整检查。验证通过才覆盖模拟地形。
- `assets/js/geo/live-open-elevation.js`：新增页面“获取公开地形”按钮，在支持外部请求和跨域像素读取的环境直接加载瓦片；失败时展示原因，不覆盖原地图。
- `assets/data/real_elevation.js`：本次交付为 `null` 占位；只有网络成功生成后才是实测来源的 DEM 处理产物。
- 重要限制：真实高程只是地形；道路、桥体、建筑及 FAST 反射面仍为概念建模，既有坐标不具备全量测绘配准。

## 2. 花江模拟驾驶改造

- `assets/js/scene/engine.js`：跟车模式加入独立车尾面、车身、车顶、前后挡风玻璃、左右门侧、轮胎、尾灯、前灯；旧版只有基础轮廓。
- `assets/js/drive/controller.js`：新增受控虚拟车道偏移（左右各至多 7 场景单位）、观景驻留、模拟鸣笛；改进跟车镜头，让整个车尾轮廓保持在画面内。自动路径依旧锁定，变道不等于真实驾驶物理。
- `assets/js/drive/drive-ui.js` 与 `assets/css/v8-upgrade.css`：增加对应按钮，并优化手机端操作入口与车内挡风框、方向盘及仪表台示意。
- 键盘：`A/D` 是虚拟车道偏移；左右箭头或 `Q/E` 是左右环顾；空格暂停；数字 1—4 切视角；Esc 退出。控制仅用于演示，不能作为驾驶培训。
- 尚不足之处：车辆不是授权的高精度三维汽车资产，也不是带物理碰撞和车轮悬架的自由驾驶系统；桥面、路幅与两岸接线没有工程实测配准。

## 3. 中国天眼科普游戏改造

- 新 `assets/js/fast/immersive-lab.js` 取代以多项选择题为主体的旧游戏。保留 `NS.FastGame` 统一接口及原入口，避免破坏首页与地图跳转。
- 游戏现在使用可以用鼠标／触屏拖动旋转、滚轮缩放的透视三维示意画布，生成反射面网格、悬索与支撑塔的空间轮廓。
- 任务一：绕场景寻找三处可能被遮挡的无线干扰装置并关闭；任务二：在可旋转的分区模型中巡检半径 3、8、21 公里的模拟检查点，并阅读各自说明；任务三：操作虚拟接收器的方位和俯仰，调谐到合成目标方向。完成后显示科学解释、可重玩与退出。
- 本玩法**不是 WebGL 工程级 FAST 三维孪生，也不是射电观测仿真软件**；半径区分来自规范概念，但示例点位置和信号完全是教学模拟。

## 4. 全中文展示

- 公众界面的序章、导航栏、菜单、模式卡、数据库字段表头、遥测提示及游戏 HUD 均中文化。
- 用户显示“建筑与地点／地点档案”，内部 `nodes` 字段保留以保证数据库兼容；用户可见数据表隐藏原始英文编号，将常见类型和状态转成中文。
- 对涉及真实键盘的 `A/D`、`Esc`、原始数据来源中必需的专有名词和规范版本号保留必要标识。未修改程序键名、外部版权信息及项目文件后缀。

## 6. 优先后续任务

第一优先：用户联网下载公开地形并检查高程范围、像素完整度与来源许可证；第二优先：配准桥体及双岸道路，完善真实桥塔比例和驾驶物理；第三优先：以可授权的公开图像和用户调研实拍替换示意地形贴图、建筑与人物信息；第四优先：如具备许可，引入 Three.js/GLB 格式真实汽车及 WebGL 场景。
