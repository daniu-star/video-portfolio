# 贵州3D交互地图 V26｜北盘江水域、峡谷游船和持续电影镜头

## 实际修改

- 原 `engine.js` 中的河面是低透明度细带，河面高度与桥面视角不一致。新增 `huajiang-river-v26.js` 的分段河面，中心参考 `650 - 625 = 25` 场景单位，并以局部单向坡度表示水流沿河谷下降。水面宽度、弯曲和起伏属于教学场景的模拟几何，未使用真实河道中心线或水文测量值。
- Canvas 地形渲染时显示可见水面、窄纹理和视觉反光。WebGL2 在支持设备上增加单独的可深度检测水面网格和程序化波纹；不可用自动回退 Canvas。仍然没有物理流体求解器、反射探针和真实影像材质。
- 新增 `river-cruise-v26.js` 游船体验和独立船体模型。船首、跟船、航拍三种视角；动力滑块；暂停、重启、退出。以一维河道约束+简化推力/阻力积分计算运动；不会冲岸、逆坡或任意穿越山体，未模拟流速、浪流、航行许可与真实船舶性能。
- 电影观景成为默认且持续启用的地形画面模式，按钮用于重置电影镜头。自动驾驶的驾驶位、乘客位、跟车和电影镜头共享地形绘制；WebGL2 相机按 `cam.pose.eye/look` 更新，与 Canvas 3D投影统一。
- 对原有 `journeyBar` 的绝对定位冲突做了覆盖，保持为紧凑悬浮入口，不再拉伸成全屏块。
- 原始 `database.bundle.js`、模拟采样地形、SQLite数据库、JSON配置、工具脚本和原有NPC游戏保持不变。

## 地理与史实依据

- 花江峡谷大桥跨越北盘江，桥下北盘江水域可观赏峡谷风景，并存在游船码头与公开报道的峡谷游船体验。2025年景区试运营资料和2026年8月地方报道可交叉验证。
- 桥面距水面约625米为公开工程指标。引入的是相对场景单位，用于保持桥—水视觉比例，不能由此推出真实海拔或实时水位。
- 河宽、船体、模拟速度、样条控制点和岸线属于教学场景。目前 `assets/data/real_elevation.js` 是否填入真实DEM，须以其文件内容及数据来源状态判断。V26未实际取得、配准新的DEM、影像纹理或水文站数据。

## 浏览器测试

1. 首次进入地图，跳过引导后可见底部小型入口栏，花江峡谷大桥下显示北盘江示意水面。
2. 游船可点击启动。船首、跟船和航拍镜头切换正常；动力、暂停、重启和退出正常；退出时恢复地图镜头。
3. 自动过桥驾驶位和电影位均能工作，保持 `cinema-focus`，`cam.pose`有效。
4. 390px和320px视口能够完成游船操作，无横向溢出；脚本异常数为0。
5. 101点水域采样的河面纵坡未出现逆坡，在桥轴处与桥面相差625场景单位。
6. 当前测试容器不支持WebGL2上下文，因此WebGL2新水面渲染尚未完成GPU或真实设备验收；测试截图由Canvas回退模式获得。

## 后续工程门槛

- 实际高精度地形需要带地理参考的30米或更高分辨率DEM、桥下河流中心线、实际水位基准及桥梁BIM/竣工模型。
- 基于 DEM 必须检查河道与桥位地理配准及岸线/水面不相交；建立LOD与GPU硬件帧率基准。
- 若要实现真实水流、船岸碰撞、船体六自由度动力学与物理反射，需要更完整的WebGL/WebGPU渲染和经过验证的船舶物理参数。
- 本轮不使用 Meshy / paid 3D 资产生成，不声称已获得专业Blender Form/Runtime Gate批准。
