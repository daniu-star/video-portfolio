# V31 过桥驾驶动力学与三维道路升级说明

## 实施范围

本轮保留原 V30 中全部原始数据与配置。改变的核心从72秒固定进度播放调整为按距离积分的简化车辆动力学，新增操作与反馈，不涉及真实道路测绘、车辆标定、实体碰撞或法规意义的驾驶训练。

### 用户可用的操作

- **自动巡航** 默认启用，干燥路面目标约70 km/h，湿滑演示目标约50 km/h。
- **W / 油门** 按住进入手动模式并加速，**S / 刹车** 按住减速，**A/D或左右箭头** 控制限定范围内的横向位置；手机使用油门、刹车与方向按钮。
- **P** 切换自动巡航，数字键1—4切换视角，Q/E临时看左右侧，空格暂停，Esc退出。
- 可以切换干燥和湿滑教学路面，观察制动及巡航表现的差异；不会把天气演示伪装成真实高速路况。
- 5个既有桥梁知识任务全部保留，任务弹出时暂停模拟车，并允许切换所需视角。

## 计算机制

采用简化的纵向力平衡

`m·a = F_drive - F_brake - 0.5·rho·CdA·v² - Crr·m·g·cos(slope) - m·g·sin(slope)`

以短时间步积分速度与行驶距离，使用路面附着系数限制制动与加速度。车辆侧向动作被约束在道路宽度内，附带柔和阻尼回正。悬架采用弹簧—阻尼近似；相机使用指数阻尼，尽量避免帧率变化造成突跳。

路线由V30原有14个控制点重建为连续Hermite曲线，并按实际模型弧长计算进度。将此前不合理的引桥坡度调整为概念上较温和的数值。游戏场景运动速度与2.4倍教学时间明确分开。

## 道路表现变化

- 保留近裁剪与桥面净空修复。
- 将道路写成连续多段的三维多边形，给同一条路加入车道标线、两侧护栏、立柱与反光标。
- 第三人称通用车补充随行驶距离变化的车轮辐条动画，同时缩小车体尺寸，降低与路面比例失调。
- 控制区采用仪表加踏板布局，显示速度、坡度、横向加速度与累计里程。
- 任务卡移至视角按钮的对侧，解决浮层遮挡切换按钮的问题。

## 测试边界与证据

本轮使用系统Chromium通过源码内联加载进行离线浏览器测试。1280×800与390×844的自动巡航、手动加速、制动、侧向位置、湿滑模式、第三人称视角、返回地图、全部五个知识任务均测试通过，未检测到页面脚本异常与横向溢出。

1201点连续道路检查得到总路径约3984个场景单位，坡度区间约 **-6.33% 至 +4.68%**。干燥与湿滑0.8秒制动测试在同初速20m/s下分别降至约15.16m/s与15.92m/s。侧向动作限制在±10.5场景单位内。这些测试证明教学模型在设定规则下运转，**不能证明与真实车辆一致**。

**仍未完成** 实测DEM、道路工程线形、护栏CAD、现场照片纹理、车辆轮胎模型标定、碰撞检测、真实雨天轮胎力学、全WebGL物体深度遮挡、GPU帧率及物理模型独立验证。现有Canvas2D渲染与概念几何依然限制视觉真实感，不能称为影视级3D或工程级物理引擎。
