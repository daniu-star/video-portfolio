# V27 双工程总览、花江水域及第一人称渲染修复

## 版本目标

在 V26 多文件工程上实施四项修复。双区域总览以原有两套地形采样分别构成可识别的三维场景，增加清晰的双地点入口，减少大面积资料面板遮挡。花江河道的教学中心线延伸至峡谷场景边界附近，水域从桥下连续延伸至两个可见方向。游船入口位于模型内的河岸码头附近，用户点击“上船”开始体验。驾驶位与船首视角采用稳定的前景构件，关闭在贴近地面视角下容易产生跳动的轮廓描边。

## 文件变更

- `assets/js/geo/huajiang-river-v26.js` 延长演示河段，并增加河面中心线、岸边缓坡处理与登船锚点。`landHeight` 只改变渲染时使用的地形高度，不覆写原始高程采样。
- `assets/js/scene/engine.js` 扩展河面并绘制简化码头、登船提示坐标和观光船多面体；提升双地点地形层次；在驾驶、游船模式禁用近景等高线及部分容易遮挡镜头的场景物体。
- `assets/js/scene/webgl-terrain-v25.js` 在可用 WebGL2 情况下使用同一河道切坡显示模型，保留自动回退 Canvas 的机制；未在本环境完成真实 GPU 验收。
- `assets/js/drive/river-cruise-v26.js` 从新码头锚点启动，船首视角的相机不再依赖甲板晃动。
- `assets/js/app.js` 调整总览镜头；`assets/js/ux/v27-overview-ui.js` 新增双地点交互卡片。
- `assets/css/v27-scenic-hydrology.css` 提供上船提示、总览设计、首人称稳定视窗和移动适配。
- `index.html` 增加上船提示、双地点选择入口、车内前景组件；保留原有导航与游戏系统。
- `config/v27_hydrology_cinema.json` 声明各模型的数据来源和验证状态。

## 数据与真实性界限

V27保留所有原始地形数据、数据库和既有配置。桥面模型 `y=650` 与河面参考 `y=25` 的差值为625个场景单位，这是公开的桥面到江面高度指标在教学模型中的尺度约束。河道长度、平面曲线、深度、宽度、码头位置、船型、航行线路以及切坡后的岸线均是模拟，不能用于导航、施工、工程核算或水文研究。V27尚未导入真实 DEM、实测河道、BIM/IFC 或运营方船舶模型。

## 交互与稳定性

船首视角仅使用稳定的屏幕空间船首近景；跟船视角使用低多边形船舱模型；过桥驾驶位由稳定驾驶舱前景配合演示道路，相机仍基于概念线路。通过限制投影近裁剪范围，避免顶点接近相机时形成瞬时跨屏多边形；取消动态视角下等高线与岩壁描边，以减少频闪。未执行长期硬件帧时间与 GPU 模拟器覆盖测试。

## 已执行验收

- Chromium 内联运行脚本验证入口、上船按钮点击、切换第一人称、退出和回到双地点总览。
- 390px 窄屏验证上船、镜头切换、双地点入口跳转以及无横向溢出。
- 驾驶位进入、电影视角切换和退出返回地图。
- JavaScript `node --check` 和 ZIP 路径完整性检查。
- 原始工程路径、关键配置、`assets/data` 文件保持完整；已在打包校验日志记录摘要。

## 尚未通过的关卡

- 无真实测绘 DEM、水面实测高程、船舶 CAD、桥梁 BIM。
- 未经过 Blender 高精度资产生成、模型拓扑检查与真实 GPU 性能测试。当前实现仍是教学场景概念模型，不应宣传为影视级或工程级真实仿真。
- 仍需实机对照检查 WebGL2 水面遮挡、航迹安全及 60fps 性能稳定性。
