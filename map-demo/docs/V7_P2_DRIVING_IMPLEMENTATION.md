# V7 第二阶段：花江峡谷大桥概念通行体验｜工程实施说明

> 完成日期：2026-10-22。开发基础：V7 第一阶段 G0 + G1，保留原有地图、建筑、数据库、故事、时间轴与图片审批管线。**本阶段 G2 是路线锁定的概念通行体验，不是已核验真实道路上的自由驾驶游戏。**

## 01. 入口与体验闭环

用户有两种入口：

1. 进入地图后，点击界面左侧「🚘 驶过花江峡谷大桥」快捷入口，打开行驶前说明；
2. 切换花江场景，点击「六枝至安龙高速·花江段」这条模拟道路，打开道路资料卡，再点击「从概念桥头出发」。其他模拟道路不提供驾驶选项，FAST 道路也不允许模拟驶入核心设施。

路线状态机 `idle → prepare → active ↔ paused → complete → replay / exit`：必须确认后才能开始；默认驾驶位，可改乘客位、跟车或电影视角。途中可以暂停、选择节奏、拖动进度，查看分阶段文案。完成后可再体验或返回进入前地图。

如果原来时间轴处在通车前，运行演示时暂时切到 `timeline >= .96`（2025-09 通车后的建模阶段）；退出时恢复先前进度。原有场景、选中对象、展示资料面板、相机姿态、模式均已加入恢复快照。

## 02. 构建内容及代码责任

| 文件 | 功能 | 不做的事 |
|---|---|---|
| `assets/js/drive/route.js` | 独立定义花江概念路线控制点、插值、朝向与七段叙事检查点 | 不生成可导航路网、不推定限速/车道法律属性 |
| `assets/js/drive/controller.js` | 有限状态机、进度推进、四种相机、控制、快照、Esc 返回 | 不做车辆物理、碰撞、自动驾驶导航 |
| `assets/js/drive/drive-ui.js` | 准备确认、驾驶 HUD、章节切换、重播、移动端操控 | 不直接控制世界渲染与经纬度 |
| `assets/css/drive-v7.css` | 驾驶覆盖层、简化仪表、响应式布局 | 不伪造品牌内饰或真实车辆照片 |
| `assets/js/math.js` | 增加独立 pose 投影路径，保留旧 Orbit 投影 | 不宣称已切换为 WebGL/Three.js |
| `assets/js/scene/engine.js` | 独占驾驶态相机、绘制分段道路和符号车辆、禁止驾驶态地图拖动 | 不在驱动期间启动第二个 RAF 循环 |
| `assets/js/ui/feature-panel.js` | 仅为花江 `road:la_s57` 添加概念驾乘入口 | 不把其他示意道路伪装为可驾车区域 |
| `assets/js/app.js` | 防止故事与驾驶抢相机、对外保留场景切换 | 不改现有节点与建筑浏览机制 |
| `index.html` | 新入口、准备确认、驾驶 HUD、脚本顺序 | 不请求在线地图服务 |

**路线自有 ID** `huajiang_bridge_demo`，对应现有示意道路 `road:la_s57`。路径起于概念引桥，桥面中段与既有 V6 场景的 `y=650` 模型对齐，在对岸的**虚拟安全终点**结束。沿线纵坡、横向偏移、车道尺寸、桥头位置没有实测保证。用户在桥面中段看到桥面距水面约 625 米、主桥跨径约 1420 米的参考信息，必须同时看到场景几何为模拟的提示。

## 03. 可用操作

- **鼠标/触控**：从快捷入口或道路资料打开准备卡；四个按钮切视角；暂停/继续；拖动 0—100% 进度条；舒缓/标准/快速（**播放节奏，不是真实车速**）；「模拟依据」解释数据等级；「退出驾驶」恢复地图。
- **键盘**：`Esc` 退出当前准备/驾驶模式，`Space` 暂停/继续，`1—4` 切视角，`←/→` 或 `A/D` 仅用于**短暂环顾**，不改变道路位置。`W/S` 不提供油门和刹车，以避免错误地暗示自由驾驶已完成。
- **自动叙事七幕**：概念引桥、桥头、主塔、跨中峡谷、另一侧视角、离桥、虚拟终点。叙事按路径进度触发而不是绝对时钟触发；暂停和拖动都保持一致。

## 04. 真实性、伦理和交互约束

1. 当前地形为程序化模拟，桥梁为场景几何。不能把截图解释成实景、精确高程或物理驾驶模拟。
2. 现有道路控制点 `SIMULATED`，不用于 GPS、路径规划或游客停车指引；特别不建议用户在高速路段实际停车拍摄。
3. FAST 场景内所有道路均不开放该模拟驾驶；此阶段没有科研核心区通行功能。
4. 进入前必须明确同意「路线模拟，非现实导航」；HUD 顶部持续显示 `SIMULATED ROUTE · NOT NAVIGATION`，并提供展开的来源说明。
5. 数据库仍是 V7 第一阶段 584 个空间对象、0 张获批发布影像，未为沉浸感编造现场建筑照片。
6. 数字“625 m”“1420 m”作为工程参考指标，不强行以场景中 y 轴距离求值。

## 07. 复现与改造路线

1. 解压项目，运行 `run_windows.bat` 或 `run_mac_linux.sh`，也可直接打开 `index.html`（全部交互逻辑离线，无外部 API）。
2. 首次启动后点击「进入3D地图」→「🚘 驶过花江峡谷大桥」→「开始概念穿越」。
3. 如果要接入真实路网，先修改 `assets/js/drive/route.js` 的 `status/source/points`，并在真实通行信息得到核验之前继续保持 `SIMULATED` 标签；不能仅替换点数组就提升为 `VERIFIED`。
4. 修改相机机制应首先运行 `qa/test_v7_phase2_browser.py`，尤其是退出快照与 20 次连续进入退出检查。
