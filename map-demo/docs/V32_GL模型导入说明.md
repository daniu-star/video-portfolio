# V32 可编辑三维资产

- `assets/models/v32_bridge_concept.glb` 道路、护栏、悬索桥主塔、主缆和吊索的概念三维几何。
- `assets/models/v32_car_concept.glb` 通用汽车概念几何。
- `assets/models/v32_asset_manifest.json` 源代码、许可、面数和SHA256。

两项资产可在支持GLB的三维软件中导入。场景坐标为教学场景坐标，不是实测地理坐标。由于程序化模型由单面三角形展开生成，尚未经过专业重拓扑、UV解包、材质烘焙和Blender审核。它们提供进一步加工的几何基础；游戏运行仍以JS程序化几何为准。
