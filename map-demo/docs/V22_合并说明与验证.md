# V22 合并修复与交付说明

## 合并原则

本版以用户上传的 `Map demo(2).zip` 为唯一原始数据与配置基线，保留原工程目录 `Map demo/`。V21 只作为新增角色任务、桥梁与道路游戏、物理教学实验及渲染增强的代码来源。所有新增模块均独立保存在对应的 CSS、JS 和配置路径中。

比对发现 `Map demo(2).zip` 与此前 `Map demo(1).zip` 完全相同（SHA-256 为 `93a73858acd55d54aa6250945eb95160cfcdd7cabac51178758c00affbdb1589`）。因此，判断“资源缺失”不能只依靠版本文件数，需要分别检查数据文件的保留、运行时的加载状态和场景渲染结果。

## 文件合并结果

- 原始文件数：145。
- 原始路径保留：145，无路径缺失。
- 原始文件字节不变：139。
- 因游戏新增功能而修改的原始应用文件：6，详见 `qa/v22_merge_validation.json`。
- 原始 `assets/data/`、`database/`、`config/` 下所有文件均保持原始字节内容，未替换地形、道路、建筑、元数据或原始配置。
- `README.md` 维持原工程版本不变。新增改动说明另存为本文件。
- 原始 `config/project_manifest.json` 与 `config/build_manifest.json` 均未覆盖；新增 `config/merge_v22.json` 单独记录版本合并信息。先前版本新增的配置 `config/visual_physics_v21.json` 仍在。

## 地形与路网状态

原始工程 `assets/data/database.bundle.js` 含两处区域共 10090 个离线地形采样点；建筑实例 496 个；道路对象 23 个。这些对象和原工程数据库 `database/spatial_demo.db` 仍然保留。浏览器已确认该数据可访问。

但两份上传源中的 `assets/data/real_elevation.js` 为 `null`，`assets/data/offline_roads.js` 状态为 `missing`。这表示原始文件包**没有内置真正的公开高程瓦片或已导入的开放道路中心线**。保留数据文件并不等于已取得实测 DEM，本版不能虚称真实高程已恢复。

原工程保留了 `assets/js/geo/offline-terrain.js`、`assets/js/geo/live-open-elevation.js` 与原配套高程及路网导入工具。联网获取公开数据仍依赖网络可达性、数据许可和来源核验。本版不会编造真实高程或虚构路网。

## 视觉与交互修复

- 默认视觉主题恢复为原工程 `nebula`（深空星云）；V21 `daylight`（自然日光）作为可选主题保留。
- 首次进入的引导由大面积左侧浮层改为居中对话框，桌面宽约354px，390px移动端宽342px，320px移动端宽292px。
- 背景轻度模糊并保留原始场景可见；可选择开始引导或直接查看地图，也支持按 Esc 与点击遮罩退出。
- 引导进入地图观察后，自动切换为较紧凑的辅助卡片，避免继续覆盖画面中央。
- 原有游戏中心、FAST 三角色双时代任务、大桥观察、公路货车、科研与桥梁物理教学实验均保留。
- “我的发现”新增“查看原始地形与配置状态”入口，展示运行时实际加载对象数，区分模拟地形与真实高程。

## 实际测试

- Chromium 内联资源测试 1440×900、390×844、320×700，均验证初始居中弹窗、时间切换、结果页、档案页、数据状态及地图切换。
- 另行验证游戏中心、FAST、桥梁与货车入口，以及物理教学实验均可打开，未记录未捕获的脚本异常。
- 离线资源按原工程路径检查引用齐全，源项目配置和数据库均与上传包原样一致。
- 由于本环境阻止浏览器访问本机 HTTP 地址，浏览器功能检查采用内联 CSS/JS 页面，**不能等同于通过真实 URL、在线地形 SDK 或不同设备的全部测试**。
- 尚未对真实 DEM 导入、地图服务商 API 授权以及真实玩家的完整任务通关展开测试。

## 使用方式

解压 ZIP 得到 `Map demo/`，按照原工程的 `README.md` 使用 `run_windows.bat` 或 `run_mac_linux.sh` 启动，并从 `index.html` 进入。不要删除 `assets/`、`database/`、`config/` 或 `tools/`。

如需要导入实测地形或道路，请优先使用原工程保留的工具，在独立副本中完成并核验其数据范围、来源和许可，再替换对应数据源。开发时不要让新增视觉或游戏脚本覆盖用户的原始配置。
