# V23 交互修复与天眼像素游戏重构

## 一、设计目的

本轮保留 V22 的 HTML、CSS、JS、数据库、地形采样、道路资源、配置、工具和运行脚本，以 V22 为直接基线。针对三个用户反馈分别修改。

### 山体不明显

- 保留原始 `assets/data/database.bundle.js`、`real_elevation.js`、`offline_roads.js` 以及全部原有配置数据，无替换和删减。
- 在 `assets/js/scene/engine.js` 中提高近景网格细度，强化坡面法向量与方向光形成的明暗对比，减少远景雾化，陡坡增加轻微棱线阴影。
- **这是渲染清晰度优化，不代表重新获取了真实高程资料**。原工程标注的实测高程缺失状态保持不变。场景依然为概念地形。

### 大桥观察任务挡住视角

- `assets/css/v23-terrain-bridge.css` 将任务改为贴右下的非模态说明卡。移动端变为屏幕下方较矮的卡片，尽量露出桥梁。
- 相机四视角控制与左右观察控制始终可点。任务卡内也提供“向左看”“向右看”以及两个指定视角按钮。
- 增加“收起说明，看清桥面”切换；不必退出任务就能调整相机。
- 观察进度仍需亲手触发两个指定视角，回答前不能跳过。

### 中国天眼冒险完全重构

- 当前游戏入口启动 `assets/js/fast/pixel-journey-v23.js`，不再要求玩家理解旧有三栏实验室或任务树。
- 玩家选择施工人员、科学家或游客。不同身份分别对应建设时期、正式运行后和科普参观时期；避免2011年的角色使用2019年才开始施行的规则。
- 每个身份有五站，总计十五段独立NPC情境。NPC、对白、任务委托、奖励名称均为原创教学内容；并非受访者原话。
- 每站固定流程为 **点击前进 → 到站 → 点击NPC → 两句对话 → 三选一问题 → 答案解释 → 获得知识卡 → 解锁下一站**。
- 错误答案会解释原因，不扣除生命值，不封锁后续游戏；正确答案解锁新地点。本地保存各身份已完成站点与知识卡。
- 画面使用原创2D像素人物、远山与道路、不同身份服装及NPC职业差异。造型以经典横版冒险的低分辨率叙事体验为参考，不复制任何现有游戏人物或资源。
- 路线为教学示意，不是到FAST科研核心区的现实通行路线，不提供真实道路导航或准入许可。

## 四、现有技术边界

主3D地图使用 Canvas 2D 投影。虽然本版提高了坡面辨识度，但没有补充实测DEM、摄影测量模型或真实车辆与结构物理仿真。天眼像素游戏的角色位置、道路和建筑均为原创插画，与原地图的地理坐标没有严格对应。

按照原工程说明，解压后运行 `run_windows.bat` 或 `run_mac_linux.sh`，再访问本地开发服务器地址。直接打开 `index.html` 时部分浏览器对本地缓存与资源访问可能有限制。请从原工程入口访问新版天眼故事。
