# 《肉身审计局》v10：角色因果、导演镜头与文案减法

**版本性质**：以 v9 可运行工程为基础的真实代码修订，而非新增设想。保留三幕、3D 透视、第一人称问诊与双边数据账本；本轮不替换已有低多边形资产。时间：2026-10-28。

## 1. 修订判据：镜头不替人物“哭”

v9 的根本错误，是把“某幕完成”直接等同“某人遭受排斥”。例如 `showUrbanContrast(true)` 无条件触发 `burst('gate')`，因而林舟顺利取得服务入口也被宣告“被挡在门外”。类似地，伊森完成数据调用时，先前的血色镜头容易让玩家误以为平台管理者同样是受压迫者。第二幕玩家已经纠正遗漏，仍被固定的“这句话没了”定性，也抹去了玩家行动的意义。

**v10 以实际事件而非角色标签、章节进度驱动导演状态。** 红色只意味着本次行动中确实发生的限制、未纠正的遗漏或劳动终止；青色意味着获得入口、完成纠正或真实分账；铜色意味着控制台调用、管理和收益；警讯呈稳重提示色，不做压迫隐喻。

## 2. 人物、行为和镜头的一致性矩阵

| 本轮具体条件 | AI / 账本真实输出 | 镜头 | 要让玩家明白的事 |
|---|---|---|---|
| 周远：未报明确警讯、旧资料不可得 | 本平台要求先补资料才可申请人工复核 | 暗红 · **先补档案** | 障碍来自这套服务分流条件，不是日结工的身体天生更差 |
| 林舟：未报明确警讯、旧资料已授权且可检索 | 本平台允许提交人工复核申请（**不等于已预约**） | 冷青 · **入口开放** | 他获得了较顺畅的服务入口；另一个人未必拥有同样资料 |
| 林舟：主动不授权旧记录 | 也会遇到本平台的档案门槛 | 暗红 | **不是阶级标签自动触发**，而是资料可得性和规则共同作用 |
| 任意人：报告持续胸痛、呼吸困难等警讯 | 指向紧急医疗帮助 | 暖白 / 米金 · **警讯优先** | 紧急征象不得被档案不足降级 |
| 任意人：不确定危险伴随症状 | 先核实情况，不启动旧档案分流 | 米金 · **待核实** | 不知道不等于没有，不拿资料缺口推断安全 |
| 赵伯或许阿姨：核对并补回漏记句子 | 保存纠正后的摘要 | 青色 · **找回** | 玩家行动恢复了重要证据 |
| 赵伯或许阿姨：跳过核对 | 保存不完整摘要 | 暗红 · **漏记** | 后果发生在记录，而不是凭空改变身体 |
| 伊森：从平台首次调用已有样本 | 账本新增本次收入，工人分成按合同产生 | 铜色 · **控制台收益** | 他处在管理、调用与收益一侧，非同样遭排斥 |
| 阿玛拉：第 10 份采集完成，当前批次不再续工 | 合同仍限制样本使用；工作结束 | 暗红 · **工位熄灯** | 人离岗，数据在授权范围内仍可能被使用 |
| 所有人：进入终章 | 逐幕按其真实操作给出结果 | 中性冷色 | **三个角色不是同一种遭遇** |

注意：这些流程属于**虚构教学模拟**，并非现成医院的真实审核规则或真实国家／阶级群体的临床风险数据。区别在于可用资料、许可、流程、权力，不是由国籍、肤色、户籍或职业直接赋予病情。

## 3. 最小但真实的玩法因果修复

第一幕旧代码只有疾病相关的聊天建议，没有给出“人工复核申请状态”，却在结尾突然说谁被拦阻。此处现已在引擎的 `assessConversation()` 增加独立 `serviceRoute` 字段，并让 AI 在聊天完成时明确告知本平台服务入口的情况：

- 没有旧资料且没有已知警讯：提示先补旧档案后才能申请本平台人工复核；
- 可查到已授权的旧资料且没有已知警讯：允许申请，不冒充已完成预约；
- 报告紧急警讯：跳过分流，提示及时获取真实医疗帮助；
- 不确定警讯：先核实，不将资料缺口当成分流决定。

事后的双人报告由同一个引擎生成，既呈现**本人已经得到的消息**，也通过相同症状、相同资料授权意愿，推演另一人的资料可得性差异。明确标注对方是模拟对照，不伪造已发生的问诊。

## 4. 文案减法：不再用小字重复剧本

| 旧表达类型 | 新规则 |
|---|---|
| 开场先讲三段理论命题、强调三种抽象权力 | 一句邀请：**三个普通人，三种数据经历。先跟着一个人走进去。** |
| 一幕里“你被挡住”“同样的症状”“资料门槛”连续出现三次 | 只有一次电影化短句、一次真实结果、一次双人对照 |
| 林舟也听“被挡在门外” | 实际通过时说**入口开放了**；若拒绝读取旧资料，才出现对应的阻碍 |
| 第二幕无论纠正与否都说“这句话没了” | 纠正则**你把漏掉的那句话找回来了**；不纠正才是**仍没被记进来** |
| 伊森看到血色受害者大字 | **平台调用30G，采集者分到0G／8G**，使用控制台的铜色中性镜头 |
| 大段论文式注释与低于11px微型文字 | 删除重复小字；必要医学安全与虚构边界在帮助／展开详情中保留 |
| 结局说每个人“被拒绝、被删减、被利用” | 三张卡片**分别陈述玩家真实经历**，允许受益与被限制并存 |

**展示密度**：第一幕主报告首屏只保留一条问诊结果、两个人的入口差异、一句说明和一个现实选择。资料完整度分数、算法争议机制等放进折叠详情。移动端对比恢复为双栏紧凑卡片，保留可读字号，不以 9px 小字硬塞整页。

## 5. 导演系统的语义边界

技术改动位于 `js/director-v9.js`（沿用文件名避免旧入口失效）和 `css/director-v9.css`。新增 `access / urgent / unclear / restored / control / shared` 语义；镜头结束自动撤除场景调色，防止红色风格串到后续报告。报告本身默认使用中性的暖白证据界面，只有实际遇到门槛时才使用针对性的强调色。

**一条严格的写作原则**：镜头必须帮助玩家理解“发生了什么”，不能反过来要求事实迎合镜头。

## 6. 自动化测试与证明边界

- 规则与 3D 几何：`npm test`，**17/17 通过**（原 16 项 + 本轮服务路径用例）。
- Chromium 页面注入式测试：林舟允许读取旧记录（冷青/可申请），周远旧记录缺失（暗红/要求补档），林舟拒绝读取旧记录（暗红/要求补档），林舟报告警讯（米金/优先就医），四个组合的实际结果与镜头状态一致，且所测路径没有未处理页面异常。
- 本轮在修改服务路径之前，还跑通一次周远从第一幕到赵伯纠正、伊森首次调用与终章的主路径；**修改之后的整部游戏跨设备完整回归测试尚需再次开展**。此前测试期间一次长流程运行在执行到第二组移动路径时因浏览器驱动中断，不能算作那一组已通过。
- GPU WebGL 真机测试、真实零基础用户盲测、高质量角色动画均未完成，不宣称达到商业 AAA 品质。

## 7. 下一轮建议（不是本轮已完成的内容）

重点做**后果而非更多文字**：周远的误工决定能否影响第二天，林舟的便捷入口是否兑现为一次实际预约，赵伯的摘要纠正是否带来一次真实的基层联系，阿玛拉的合同与返工是否反映劳动成本。玩家在每幕都能带走一项**事实变化**，而不仅是学到概念。

**最终主题**：不是“所有人都被机器压迫”，而是**同一套数据制度，可能让一些人被挡住、一些人顺利通过、一些人掌握复用与分配的权力**。这才是身体差异如何被媒介规则组织起来的叙事重点。
