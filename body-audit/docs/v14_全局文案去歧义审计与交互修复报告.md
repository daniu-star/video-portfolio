# 《肉身审计局》v14：全局文案去歧义审计与交互修复报告

**版本性质**：基于 v13 完整游戏工程的实际代码修订，不是仅供参考的改写方案。  
**本轮焦点**：让普通玩家不依赖媒介理论背景，也能知道谁说了什么、AI记录了什么、结果为何发生、游戏做到了哪一步。  
**更新范围**：全部三幕的关键剧情提示、第二幕聊天及报告、跨幕衔接、结局与若干产品式界面提示。保留原来的3D探索、角色规则和工厂账本。

## 01｜问题的性质

原句 **“这句话，回来了。”** 在文艺短片里或许可以作为象征，但在游戏中它发生在玩家完成一次记录核对之后。玩家没有被告知“这句话”具体指哪句、“回来”代表什么操作、哪些记录真的改变了。结果是：玩家做对了操作，却不能用自己的话解释操作的成果。

类似问题来自五种文案模式：

1. **没有指代对象**：这句话、这一句、她、你、入口、工位，缺少明确的对象或指向。
2. **用隐喻代替事实**：回来了、没留下、熄灯了、收益回来了，没有说明真实系统状态。
3. **过早总结理论**：刚问完诊就说“它知道多少，不等于你的身体”，跳过证据展示。
4. **角色与说话人混淆**：AI在聊天中说“我刚才那份记录险些少了……”，像是AI突然替患者说话。
5. **承诺高于系统能力**：只记录了“打算联系医生”，却写成“已备好联系医疗机构的说明”，暗示已经实际产生可交付的医疗服务。

## 03｜第二幕现在怎样展示？

玩家选择赵伯，在本轮说：**“一走快就气短，坐下来好一点。”**

- **你刚才说**：“一走快就气短，坐下来好一点。”
- **AI最初记成**：“坐下来好一点。”
- **漏记的是**：“一走快就气短。”
- 如果玩家点击“请补上”，系统展示：**“AI现在已记录完整原话……”**。
- 如果玩家点击“不修改”，系统展示：**“记录仍是……就医时需要再说出完整原话。”**。

这四行都使用**玩家这一次的实际状态**生成。许阿姨也有独立的原话、初稿与遗漏项。如果她这次说“吃了药以后还是头晕，跟平时不一样”，报告会指出漏记了“跟平时不一样”，而不是播放赵伯的固定台词。

这次也纠正了报告呈现方式：原来整段 AI 初稿被打删除线，容易使玩家误以为整段记录都错误。现在初稿正常显示，**只将确切漏记内容单独突出**，并分别区分“已经补回”和“仍未补回”。

## 04｜不是只要改文案就行：修复了三处因果暗示

**A. 医疗预约不能凭空发生。** 选择“找附近医生”只代表角色准备联系，游戏没有发起真实预约。因此相关文案现在写“你打算联系附近的医生；目前尚未预约”。选择告诉家人也只代表意愿，并非已实际发送消息。

**B. 不上传不是没有病历。** 对老人选择暂时不上传旧资料，AI会准确回应“你暂时不上传旧记录”，不再一律回答“没有记录……”。

**C. 不确定不等于被旧病历拒绝。** 如果第一幕报告的紧急伴随情况仍未确定，结局写的是“伴随症状还没核实，系统暂时没有作出复核分流”，不能被强行讲成“缺少旧档案所以被拒”。

- **真实浏览器流程：7条专项路径已测**：赵伯补记（桌面）、赵伯不补记（390px手机）、许阿姨补记（390px手机）、许阿姨不补记（桌面）、周远问诊（桌面）、林舟问诊（390px手机）、伊森平台首次买断调用（桌面）。已测路径未捕获页面 JS 异常。
- 第二幕4条路径均核对了**聊天原话、初稿、遗漏项、报告标题、过场副标题、跨幕衔接**六处是否指向同一数据。
- 测试环境禁用GPU，浏览器专项测试采用**页面注入与关闭三维循环**的方法，验证的是剧情和交互状态，不代表最终GPU性能或完整真人试玩。

## 06｜后续文案统一标准

**玩家行动后的第一句话必须能脱离上下文独立理解。** 每次关键反馈检查四个问题：

1. **谁做了什么**：AI漏记、玩家补回、平台调用、劳动者获款。
2. **哪项具体内容变化**：一走快就气短、旧病历授权、D-003、8G分成。
3. **结果是已完成、待完成还是假设**：已写入、尚未发送、可以申请但未预约、模拟对照。
4. **下一步是否真实可做**：只能给出游戏中真正能执行的按钮，不许暗示已创建不存在的服务。

主页面只放重要结果；技术细节和方法限定移到可展开区域。可以保留少量有文学张力的章节标题，但不得用隐喻替代操作结果，也不得预设某类人物必然被排除。

**完整表达范式**：*你说了“……”，AI只记下“……”。你补充了漏记的“……”，现在问诊记录已更新。* 这是这款游戏应当坚持的最低可理解性标准。
