# 《肉身审计局》v8：从“问完就走”到“每幕获得一份证据”

> 版本类型：**游戏玩法与叙事内容改造，已落实到 HTML / CSS / JS / 单文件离线版**。  
> 审核对象：v7 的三幕剧情、角色问诊流程、数据工厂及三维场景。  
> 核心目标：玩家不必先读理论，也应在完成一次操作后知道“我看到了什么、它为什么重要、与后面一幕有什么关系”。

## 0. 结论与设计总纲

v7 已解决 3D 场景能不能走、问诊室能不能聊和工厂能不能记账等“能运行”的问题，但**行为与获得感之间没有形成闭环**。玩家完成第一幕问诊后，AI说了一句咨询建议，随后又让玩家从“摘要 / 对比 / 继续”中猜哪个入口有思想价值。第二幕需要主动打开摘要才能发现漏记的症状。第三幕即使数据交易成功，也未及时将劳动者与平台的不同处境解释给玩家。

v8 改用统一的叙事闭环：

**身处具体生活 → 亲自行动 → 立即得到证据 → 看见另一种可能 → 得到一句能够带走的发现 → 自然进入下一个问题。**

三幕总问题：**当身体越来越需要通过数据来获得回答、被记录并创造价值，谁有机会成为系统认可的“有效身体”？**

- **第一幕 · 被分流**：同样的主诉为何可能因过去的资料覆盖不同，得到不同的人工复核入口？
- **第二幕 · 被记录**：一句真实说过的话，为什么可能没有成为机器可以理解的证据？
- **第三幕 · 被复用**：同一份身体动作数据，为何可以离开身体不断产生新的调用收入？

本游戏不以医疗风险、劳动价值或种族能力给人的身体打分。它追踪的是**信息覆盖、服务分流、转写完整性、授权与收益分配**的机制。具体偏差均为**明确标识的虚构教学机制**，不冒充现实AI系统测量或调查结果。

## 1. 旧版问题逐项定位与解决

| 旧问题 | 真实后果 | v8 改动 | 验收证据 |
|---|---|---|---|
| 问完诊必须自己猜“对比”按钮在哪里 | 玩家以为关卡只是一次普通AI聊天 | **完成第四轮问诊即自动生成双人物报告** | `js/game.js` 中 `urbanAnswer → showUrbanContrast(true)` |
| “对比”其实只是同一个人有/无病历 | 没有周远—林舟差异 | 同屏展示两人物的标准化对照、资料分与服务分流结果 | `showUrbanContrast()`、`compareSameSymptoms()` |
| 角色的身体状况不同，却直接把结论叫算法歧视 | 逻辑不成立 | 对照时锁定**相同的回答与授权意愿**，仅改变能否检索旧病历 | `js/engine.js` |
| 把资料分当成“健康分” | 对患者和社会阶层产生误导 | 显示“**对话资料完整度（教学模拟）**”，不显示疾病风险等级 | 自动报告双卡 |
| 只有抽象结论，没有找到具体问题规则 | 玩家无法说出偏见从哪来 | 点开“为什么这里称为算法偏见？”明确指出“连续病历→非急诊人工复核资格”的不恰当代理指标 | 报告可展开解释 |
| 普通病人不能改算法 | 角色权责不合理 | 玩家不能进入管理后台；只能在报告里查看**事后反事实推演**，而非修改真实规则 | 报告内纠偏按钮 |
| 一方完成后还得等另一方体验 | 中途退出没有收获 | 一方完成即可显示对照，另一侧始终标明“**未问诊的模拟对照**” | 周远/林舟单侧测试 |
| 报告不区分真实经历与推演 | 容易形成虚假证据 | 上半部“你刚才真实经历”，下半部“相同症状条件下的情境推演” | 结构、标签、文案 |
| 第二幕漏记信息不自动显现 | 看不到“记录如何制造身体” | 选择就医路径后自动展示“原话 / 最初摘要 / 对照人物 / 已采取行动” | `showRuralContrast()` |
| 第三幕只有账目变化，没有比较点 | 无法理解全球南北劳动差异 | 平台首次调用样本后自动显示“一次身体劳动 / 一次无须重做的复用 / 实际分成” | `showFactoryEpiphany()` |
| 三幕过渡像论文目录 | 核心问题分散 | 过渡字幕改为**第一道门 / 第二道门 / 被复用的动作**，最终报告归并为同一主线 | `showBridge()`、`renderEnd()` |
| 小屏文字太密 | 用户可能没读到关键发现 | 重要结论前置，双卡在小屏并列，底部主要操作固定，全文可纵向阅读 | 390×844截图 |

## 2. 第一幕：每个人只要问完一次，就能获得双人物报告

### 2.1 玩家完整旅程

1. 选周远或林舟，看到本人处境，走到问诊机。
2. 在“陈俊良问诊室”说出不舒服，回答时间、是否有警讯、是否授权旧资料。
3. AI给出必要的非诊断性建议（遇到胸痛等警讯时直接建议紧急医疗帮助）。
4. **不需要额外点击“对比”**，立刻弹出报告：《问的是身体，为什么先被检查的是档案？》
5. 报告首先展示**本人真实问诊**：角色姓名、AI建议、授权与否、当前对话资料完整度。
6. 下方展示**同症状同授权前提下的情境实验**：周远、林舟并列，资料完整度和模拟人工复核入口并列。
7. 玩家主动点开“为什么这里称为算法偏见”，找到错误代理指标；按“如果不以旧病历设门槛”查看反事实：双方可以申请人工复核，同时将缺项标记待核实。
8. 从报告返回咨询、切换角色实际体验，或前往第二幕。

### 2.2 为什么是一组72/90，而不是疾病风险分数

计算逻辑来自独立 `assessConversation` 函数：基础资料 28；回答时间及警讯问题 34；时间确定性附加10；有可读取旧档案附加18。对于**确定时间、无紧急警讯、双方均允许参考旧档案的标准化案例**，周远因缺少可读取档案为72/100，林舟因有旧档案为90/100。分数用于展示“系统知道多少”，不是“谁更健康”。

上述对照是为了锁定一个机制变量：**信息是否存在和是否能被机器读取**。倘若两人所说的症状不同，则不能把两种医学建议直接并列、归因为职业或阶层偏见。真实个人对话与实验对照因此严格分区。

### 2.3 明确展示被批评的“模拟错误规则”

虚构系统的非急诊人工复核候选入口使用如下代理：

- 有连续可读取旧病历 → 进入人工复核候选队列。
- 没有连续可读取旧病历 → 被要求先补齐历史资料再申请复核。

这条规则可能在信息不平等环境中产生分流偏差；它**不代表任何具名真实医院的规则**，也不等同真实AI医学诊断。出现急症警讯的模拟情形优先建议紧急医疗帮助，不得因为资料缺失降低紧急程度。

**反事实实验**：只取消“既往病历完整度是准入条件”的规定，不假设患者身体改善，也不抹除资料核验工作。修改的是服务资格，不是疾病结果。

### 2.4 示例自然文案（已纳入）

- “刚才你拿到了一份答复。现在，再看看同一台机器的另一面。”
- “你和另一个人说出同样的不舒服，系统掌握的旧资料却不一样。”
- “身体没有突然变化，变化的是机器给人的机会。”

不是在聊天中生硬说“算法偏见、阶层再生产”，而是先让人看到谁能进下一道门，再解释它的名称与原理。

### 2.5 两方完成才有第二份“实际资料”

如果玩家返回角色选择，确实亲自完成另一位的问诊，系统会在游戏状态中保存两份访问记录 `act1Visits`。为了保证对照仍然严格控制症状，报告中两张评分卡继续使用**标准化推演**，并明确告知“另一角色也曾实际体验，但本表不是把两次不同症状直接进行医学比较”。

## 3. 第二幕：一份被漏掉的原话，立即产生什么后果？

当玩家结束“赵伯”或“许阿姨”的问诊，系统立即弹出《一句话没进记录，就像它从来没发生过》。页面直观呈现：

- 本人“原本说了什么”；
- AI第一次“只留下了什么”；
- 另一位老人的可能经历（清楚标记为预设剧情，不当作真实已玩过）；
- 玩家是否纠错，以及是否只生成了联系医生或家人的**说明**（不冒充完成预约）。

第二幕的关键发现不在于“乡村老人更不会说话”，而在于**当新出现的症状被旧病历覆盖、转写遗漏未被核对、诊疗建议没有交通与联系支持时，信息到服务之间可能断裂**。具体角色都保留表达能力与主动纠正权。过渡进入下一幕的提示不引用抽象术语，而以疑问引导：**“如果人的动作也被采成数据，谁能够继续使用它？”**

## 4. 第三幕：第一笔复用收入就是一张证据

保留 v7 的立体作业区、动作录制时间、工作负荷、三种合同以及双方共享账本。当伊森首次成功调用一份已核验动作样本，**自动**出现《她做了一遍，你还能用几遍？》。内容来自交易引擎中的实际记录：

- 样本编号、原始采集者、动作类型；
- 阿玛拉完成该动作的一次性工资（15G）；
- 伊森这次调用新增收入（30G）；
- 按该样本合同实际向阿玛拉分账（买断0G、持续分账8G，限次依原有规则）。

首次使用报告不给“谁更值钱”的人格结论，而提示**身体劳动的时间不能复制，数据在授权框架下可以复用**。报告仍允许回到平台继续工作、查看双边流水或直接进入总报告。

## 5. 统一叙事结构：三道门及真正的反转

| 幕 | 玩家原先以为自己在做什么 | 玩家亲眼得到的证据 | 更深一层的问题 |
|---|---|---|---|
| 第一幕 | 向AI问诊 | 同症状、不同记录覆盖 → 非急诊复核资格被旧病历影响 | 谁被允许得到照护？ |
| 第二幕 | 向AI说明不舒服 | 原话、漏记摘要和纠错结果可以截然不同 | 谁的身体经验有资格成为系统证据？ |
| 第三幕 | 完成劳动或调用数据 | 身体劳动只做一次，数据却可重复变现并产生不同分配 | 谁决定价值回流给谁？ |

主线的哲学表达应当在**每次获得证据之后**才出现：当身体被转写为记录、评分与可交易样本，数据反过来重新安排身体在现实中的机会。此处关联萨克的媒介/生命政治思考，但具体人物、病历分、合同数字均为**教学构造**，不能被引用为萨克本人提出的实证结论。

## 6. 权限、伦理和医学安全

1. 普通日结工、职场中产和老人不能进入算法后台修改服务规则。可以提出问题、纠正自己的话、申请人工帮助，或在独立报告中观看对照。
2. 符合“同条件比较”前提才能把模拟不同服务决策归因为那条资料门槛。现实症状差别不应被偷换为阶层差别。
3. 清晰分离“对话资料完整度”与“临床风险/患病概率”。现有公式只用于前者。
4. 若模拟对话中用户报告胸痛、呼吸困难、近似晕厥等警讯，建议紧急帮助不因旧资料缺失而被降级。
5. 对照人物状态始终标注为情境推演，除非玩家真正体验过，并且也不得拿两份不同症状真实问诊直接计算所谓“算法歧视率”。
6. 不把地域、肤色、阶层设为生理能力差异的决定变量。第三幕是两类岗位与授权结构的权力差异，不是“全球南方人能力差”的刻板描述。
7. 工厂账本虚构货币与合同不是世界工资水平或平台利润数据。详细账本由同一函数记账，保证数值可核验。

## 7. 视觉与人机交互验收

- 对照报告自动弹出，但必须一键关闭、返回聊天及继续；不得在用户未完成问诊时提前弹出。
- 桌面上半屏必须能同时看到报告标题、本人实际结果和双角色评分对照入口；重要结论醒目。
- 手机 390×844 上报告上下可滑，底部“继续”保持可达；不截断文本，不出现横向拖动，不遮住关闭按钮。
- 双卡保持角色名、资料分和分流状态清晰；次要方法论折叠在 `<details>` 内，避免堵住首屏。
- 反事实按钮只操作独立报告内容，不反写故事世界的医嘱、病历或诊疗结果。
- 第二幕报告与第三幕首次调用报告都有同样的奖励节奏：**做完 → 看见证据 → 理解差异 → 自己选择继续方向**。
- 三维舞台、角色行动、碰撞和工厂流程沿用 v7，不把新增的图表和弹窗伪装成更先进的 3D 物理系统。

- `npm test`：**16/16** 规则与几何测试通过；其中新增3项专门验证双人同症状对照与急症防护。

## 10. 下一轮仍需要继续做什么

**P0 · 真实理解验收**：招募至少 5–8 位不了解媒介理论的参与者，记录他们是否能用自己的话回答三道门各是什么；检验报告是否使理解率较旧版提升。未执行前不得宣称完成零基础用户验收。

**P0 · 聊天更具个性和连续性**：现有聊天仍以有限意图与预制选项为主。允许追问“为什么旧病历能决定排队”“如果我没钱看医生怎么办”，并实现能回指既有对话信息的回答，而非只做关键词匹配。

**P1 · 对照中的现实后果**：避免只是两个分数；在有充分调查依据后加入真实的行动成本、工作请假约束、线下服务可达性，但不得从职业推断医学严重程度。

**P1 · 第三幕的劳动与许可协商**：加入平台返工要求、质量审查的可解释依据、被拒付申诉、许可到期后的复用约束；保持每次经济变化来源于流水，不凭空制造金币。

**P1 · 游戏节奏**：以真人观察决定报告应先给结论还是先给对照、是否需要可跳过的“简要解释”，把信息分层而非无节制增加文本。

**P2 · 高质量3D人物动作**：在明确的 Function / Form / Runtime 审批后，再推进骨骼、IK、抓取、精细角色与音效。不能用一张概念图代替可运行动作，也不应在没有运行门禁的情况下宣称3A品质。

## 最终判断

**这次最重要的改动不是“多一个报告”，而是让每一次操作有能够被自己观察、比较和检验的理论结果。** 玩家不是在被要求认同一个概念；他先看见两个具体人物在同一条规则下获得不同机会，才有理由追问：是身体不同，还是数据与制度让他们被不同地看见？
