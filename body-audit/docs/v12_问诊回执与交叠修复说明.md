# 《肉身审计局》v12：问诊回执去模板化与导演字幕遮挡修复

> 修订对象：v11 第一幕“问诊结束”的报告界面。此次只改真实游戏 UI 与交互流程，不替换三幕主线，不伪称完成了照片级 3D 美术。

## 一、为什么原页面不自然

1. **同一条信息说了三遍**：过场字幕讲“通过/被挡”，弹窗标题又讲一次，两张卡片再讲一次。注意力被标题而不是人物经历吸引。
2. **像后台看板，不像人物体验**：大卡片、资料完整度细节、重色结论条、反事实功能和多组按钮同时出现；玩家看到了“系统报告”，却没有看见一个人接下来能做什么。
3. **过场字幕与弹窗层级冲突**：导演字幕在 `z-index:65`，报告在 `z-index:51`。过场结束的计时器与弹窗开启靠得太近，低帧率下可能同时出现；减弱动态模式的字幕还可能持续可见。
4. **弹窗不守视口**：旧版手机端过度占满主舞台高度，底部操作有裁切风险。
5. **信息层级错误**：虚构资料分数被当作主视觉，其实玩家首先需要知道的是“本次申请怎样了”。

## 二、这次具体改动

- **重写首屏**：`陈俊良问诊室 · 回执` → `这次问诊的结果` → 角色实际申请状态 → 相同症状下的另一条模拟路径 → 真实行动选项。原本的两个立体卡片压缩为无卡片边框的并列路径。
- **保留身份因果**：周远可能因缺少记录受阻；林舟资料可查时可申请复核；如林舟拒绝授权，同样可能受阻；有紧急警讯时先提示就医。报告不声称诊断结果或已经预约医生。
- **不把情境推演冒充真实经历**：对照的另一人明确标注为“模拟路径”，只使用相同症状和授权条件的教学设定。
- **去掉默认评分展示**：72/90这样的资料完整度数值仅在自愿展开“规则如何影响结果”后显示，并强调它不是病情评分。
- **反事实仍能玩**：原有 `auditReplayButton` 仍可改变分流门槛并显示结果；现实应对 `humanCostA/B` 仍会保存选择并给出反馈。
- **杜绝标题重叠**：`showSheet()` 首先调用 `FleshDirector.clear()`，并用 CSS 确保报告出现时字幕与氛围层不可显示；减少动态模式同样适用。
- **提升阅读舒适度**：收窄报告、取消重复色块、保留行动按钮吸底但不遮盖内容；手机端明确扣除顶部导航栏高度，防止操作区裁切。
- **工程可维护**：新增 `css/receipt-v12.css`，保留原有规则引擎、JS模块、3D模块、素材和本地服务。

## 三、关键文案对照

| 元素 | 之前 | 现在 |
|---|---|---|
| 主标题 | 人工复核入口，为你开放了。 | 这次问诊的结果 |
| 事实结论 | 你通过了 / 被拒绝了（与字幕重复） | 你的复核申请入口已经开放 / 你的申请卡在了旧记录上 |
| 对照标题 | 把两个人的症状设为一样 | 如果换一个人来问 |
| 差异解释 | 同样的症状，门槛却不同…… | 同样的症状，旧记录不同，申请入口就不同。 |
| 下一步 | 提供已有记录 / 先问医生新症状 | 提供旧记录 / 问医生这次的新症状 |
| 原理分析 | 多组卡片常显 | 玩家主动展开的补充信息 |

## 四、验证

- `npm test`：**17/17通过**，包括医疗建议、记录门槛与交易规则的既有用例。
- Chromium 页面注入：通过林舟和周远的桌面报告路线；通过林舟的390×844移动端报告，并验证报告底部操作不超出视口。
- 交互断言：能够查看结果、点击现实选择、展开规则、运行反事实模拟、继续进入下一幕。
- 层级断言：报告开启后导演字幕计算后的 `display:none`，无未处理 JS 页面异常。
- 截图：`docs/qa_v12/final_desktop_fixed.png`、`final_mobile_fixed.png`。

## 五、当前仍有的限制

- 本次主要修复**第一幕报告的视觉和叙事体验**，并非三幕所有界面的全面重绘；第二幕与第三幕仍需同等水准的 UI 整合。
- 自动化浏览器测试使用 CPU 三维投影回退；实际 GPU WebGL 性能、跨浏览器适配与真人零基础玩家测试未完成。
- 角色、病历、评分、授权规则属于明确虚构的教学模型，不代表现实医院的医学算法。

## 六、打开方式

- 本 ZIP 根目录有 `index.html`，与同层 `css/`、`js/`、`assets/` 一起解压后可打开。不要只拷贝 `index.html` 而丢失配套目录。
- 另外提供完全自包含的 `肉身审计局_v12_单文件试玩.html`，可以单独双击。
- 若要启动本地开发服务，安装 Node.js 20+ 后执行 `npm start`，再打开 `http://127.0.0.1:4173`。
