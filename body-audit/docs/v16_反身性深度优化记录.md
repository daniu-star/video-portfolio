# 肉身审计局 v16｜反身性深度优化记录与后续方向

**项目依据**　v15 版《问题总结与优化方向》、上传的《数据与肉身》文档“反身性与批判”部分以及原游戏源码。

## 本轮理论目标

《数据与肉身》的“反身性与批判”主要讨论智能手表评分如何参与自我评价、AI问诊的输入与资料条件如何影响记录、动作数据如何在不同劳动关系中被采集和再利用。本轮在保留旧剧情的前提下，将游戏过程统一为“当事人的身体处境与表达、技术记录与分类、当事人根据反馈做出行动、行动再次被记录、反问规则的来源与影响”。

## 已实现的功能

| 原问题 | v16 实施变化 | 玩家能亲自看到什么 | 局限 |
|---|---|---|---|
| P01 开场目标不清 | 开场交代三幕共同任务，并更新操作帮助 | 数据如何反过来改变行动成为明确问题 | 仍需陌生玩家理解测试 |
| P02 反身性反馈不足 | 第一幕回执新增虚构设备自评58/100及三种后续选择，显示第二轮数值和生活代价 | 选择追逐数字时读数变高，本人的疲惫未必改善 | 数值为设计情境，不是生理模型 |
| P07 摘要漏记只用按钮纠正 | 第二幕新增原话、摘要与可选文本片段的校正编辑 | 错选会提示该片段不属于原话，正确选择才能修改记录 | 使用预设片段，尚无真正的自由改写和ASR |
| P04 第三幕与3D画面脱节 | 任务步骤关联到三维工位附近的屏幕坐标热点 | 可直接在场景中启动校准、动作执行与数据核验 | 尚非箱体拖拽、路径操纵与刚体模拟 |
| P08 合同选择失衡 | 一次买断19G，持续分账12G加每次复用8G，限次使用16G最多两次 | 工资即刻到账或未来分成的风险有所区别，授权产生实际后果 | 利润、议价和撤销仍是简化模型 |
| P09 休息缺少代价 | 虚构600秒班次，工作步骤与休息均消耗时间，疲劳达到阈值时样本可能被要求重录 | 不休息可能白做一段动作，休息则减少可用于采集的时间 | 没有真实职业人体工效学参数，不可据此判断健康风险 |
| P10 历史工资混淆 | 账本与屏幕继续标注历史样本，采集工资由样本合同定义 | 可以核对每份样本的报酬与后续复用 | 历史样本工资包含在合计中，仍须通过明细理解 |
| P11 终章由系统直接给结论 | 新增三选一证据判断与单条规则替换 | 玩家要回答哪种解释获得证据支持，观察另一套规则的推演 | 问题集仍预设选项，尚未支持自主输入开放论证 |
| P03/P12 画面遮挡和阅读负担 | 保留v15可收起侧面任务台，工位操作可脱离任务台完成 | 收起后人物与工位仍可操作 | 展开手机任务区时会临时覆盖部分场景 |

## 已核查的主要场景

浏览器中走通了周远问诊反馈、赵伯逐句纠错、阿玛拉签约与点击工位热点完成采集、切换伊森核对样本与调用、生成终章并切换证据判断。已保存桌面端场景截图、第一幕反身性反馈截图和移动端展开/收起界面截图。`npm run check` 共33项自动化测试通过，其中 v16 新增5项。

本机浏览器对离线网页本地地址有限制，浏览器检查通过单文件内容加载执行。部分长时间三维截图任务会因运行环境超时，因而**不将此次检查视作全设备性能验收**。

## 后续尚需继续开发的四项内容

**真实物体动作。** 当前发光工作点已与3D工位空间位置绑定，下一步应支持点击具体货箱、抓取、放入指定货架和失败时的视觉返工。物理移动是否完成应决定动作数据是否合格，避免又回到“点按钮播放动画”的形式。

**生活条件的连续演化。** 第一幕的第二轮数字已能表现追逐数据可能反过来改变生活，但尚未进入一个可持续的日程系统。可以加入时间、经济压力、工作安排和寻求帮助的多日状态，避免第二轮结果只是一段文本。

**可争论的审计结论。** 当前审计题区分证据支持与过度推断。下一步应让玩家选取具体证据、提交自己的解释，并允许两种以上合理但有所侧重的判断，支持课堂交流。

**实证边界与参与者测试。** 需让不了解媒介理论的玩家首次试玩，不解释“反身性”，记录其能否明确指出“我是为什么修改自己的行为的”“我能改变哪条记录规则”“该制度让谁获益或承担成本”。并对合同设计进行社会与经济学层面的进一步核验。

## 验收建议

以6至8位初次接触者进行盲测，记录完整通关率、第二轮评分体验率、漏记纠正的错选次数、第三幕实际使用场景点击而非侧栏按钮的比例，以及终章能否独立解释三条证据。每位玩家结束后提出三个问题。你在何处根据数字改变了行为。这个改变有什么实际代价。如果有权修改一条规则，你会调整什么。以这些回答判断游戏是否把理论问题转化为具体经验。
