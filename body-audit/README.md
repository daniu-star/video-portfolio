# 肉身审计局 v16｜反身性机制与场景交互升级

本项目为三幕离线可玩的课堂思想实验，围绕数据如何描述、评价并重新作用于身体经验而设计。已保留 v15 的右侧可折叠任务台、三维场景、六名角色及跨身份账本。新版本不依赖 CDN 或远程接口。

## 如何开始

- 解压完整工程后双击 `index.html`。
- 也可以单独打开根目录的 `肉身审计局_v16_单文件试玩.html`。
- 第一幕按人物完成虚构问诊，结果页向下找到“反身性实验”，比较设备自评和本人感受，选择下一轮行动。
- 第二幕选择“逐句核对”，从实际原话中找到漏记片段，必要时保留原记录进行对照。
- 第三幕选择合同后，可直接点击三维场景附近发光的工位操作点，依次完成校准、执行、核验，也能在右侧任务台使用同样的操作。点击“收起操作”可查看完整画面。
- 在终章的“证据审计台”切换三个议题，选择有证据支持的解释，尝试改变一条规则并观察推演结果。

## v16 新增功能

- 第一幕：设备评分反馈、玩家行为调整、虚构第二轮读数与真实感受的并列呈现。
- 第二幕：玩家直接判断哪个片段被遗漏，错选可纠正，原话回填留有记录。
- 第三幕：三维工位关联交互；模拟班次时间、负荷、休息与质量重录；三种具有不同报酬与权益条件的合同，调用时逐笔记账。
- 终章：三项可交互证据判断与规则替换实验。

## 设计及事实边界

故事中的设备分数、600秒班次、19/12/16G采集工资、30G调用收入及8G分账均为**虚构课堂规则**。它们不代表真实医疗指标、职业标准或国家收入水平。工位操作是与三维场景位置关联的交互热点和角色动画，**不是刚体物理抓取或真实人体动作捕捉**。AI问诊仅为剧情体验，不能用于诊断。

## 文件

- `css/reflexive-v16.css`：新增第二轮反馈、逐句补录、工位热点和终章审计 UI。
- `js/engine.js`：评分实验、合同报酬与动作质量的纯函数。
- `js/game.js`：交互状态与三幕事件串联。
- `js/world3d.js`：三维对象世界坐标向屏幕坐标的映射。
- `docs/v16_反身性深度优化记录.md`：详细变更、测试与剩余限制。
- `docs/qa_v16/`：浏览器检查截图、调试脚本位于 `scripts/`。
