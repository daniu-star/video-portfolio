# 明亮艺术化重构作品集网站 Spec

## Why
当前作品集网站采用深色主题（背景 #0a0a0f），整体风格偏暗淡沉闷，UI设计缺乏AIGC艺术化特征，视觉呈现不够美观专业；同时视频加载机制存在JavaScript优化空间，导致播放体验不够流畅。需要从配色体系、视觉语言、交互设计、视频性能四个维度进行全面重构。

## What Changes
- **整体配色体系从深色切换为明亮风格**：将所有CSS变量从暗色系改为明亮系，包括背景、文字、卡片、边框等
- **UI设计全面艺术化升级**：采用AIGC风格视觉语言，融入渐变光效、流体动画、创意排版、艺术化卡片设计
- **视频加载JavaScript优化**：修复视频预加载策略、添加就绪状态检测、增加加载指示器、优化播放触发逻辑
- **导航栏明亮化适配**：导航栏从深色毛玻璃改为明亮毛玻璃
- **Hero区域重新设计**：明亮背景下的Orb动画配色调整，标题渐变色适配
- **关于我时间线明亮化**：时间线卡片、渐变线条、节点圆点配色适配
- **视频卡片明亮化**：视频卡片背景、边框、悬停效果适配明亮主题
- **作品分类卡片明亮化**：分类卡片配色适配
- **联系方式区域明亮化**：联系卡片配色适配
- **页脚明亮化**：页脚配色适配
- **contact.html和video-collection.html同步明亮化**：确保全站风格统一

## Impact
- Affected specs: 全站视觉设计系统、视频加载机制
- Affected code: index.html（内联CSS+JS）、style.css、script.js、video-collection.html、contact.html

## 网站问题诊断报告

### 一、页面设计美观程度问题

1. **深色主题压抑感强**：`--bg: #0a0a0f` 背景过于黑暗，`--glass: rgba(255,255,255,0.04)` 玻璃效果几乎不可见，整体视觉沉闷
2. **色彩层次单一**：全站以 indigo/purple 渐变为主色调，缺乏色彩丰富度和视觉层次
3. **卡片设计缺乏辨识度**：所有卡片使用相同的低透明度玻璃效果，没有视觉焦点和层次区分
4. **排版缺乏艺术感**：标题使用标准字体权重和间距，缺乏创意排版和视觉张力
5. **缺少装饰性视觉元素**：页面中缺少艺术化的装饰元素（如抽象图形、渐变光斑、几何图案等）

### 二、阅读好感度与便利度问题

1. **文字对比度不足**：`--text-secondary: #9d9db3` 和 `--text-muted: #5e5e72` 在深色背景上对比度偏低
2. **视频描述信息隐藏过深**：视频简介需要hover才显示，用户难以快速了解视频内容
3. **时间线卡片背景图片干扰文字阅读**：`timeline-card::after` 使用 `rgba(10,10,15,0.85)` 遮罩，在明亮主题下需要调整
4. **技能标签滚动速度过快**：marquee动画30s周期，信息密度大时难以阅读

### 三、设计专业性与艺术性问题

1. **缺乏AIGC风格特征**：当前设计是通用的深色科技风，没有体现AI生成内容的创意性和艺术性
2. **动画效果单一**：仅有Orb动画和滚动渐入，缺少微交互和创意动效
3. **视觉语言同质化**：与大量深色科技风作品集网站雷同，缺乏个人品牌辨识度
4. **缺少创意布局**：所有区域使用标准网格布局，没有打破常规的创意排版

### 四、视频加载性能问题

1. **预加载策略不当**：IntersectionObserver仅设置 `preload='metadata'`，只加载元数据而非视频数据，导致hover播放时仍需等待加载
2. **播放触发缺少就绪检测**：`mouseenter` 直接调用 `video.play()` 而不检查 `video.readyState`，如果视频未缓冲完成会导致卡顿
3. **无加载状态指示**：视频缓冲时没有loading动画，用户无法感知加载进度
4. **无错误处理**：`video.play().catch(function() {})` 空捕获，播放失败时无反馈
5. **视频格式单一**：仅提供MP4格式，缺少WebM等更高效的格式选项
6. **全屏播放体验不佳**：点击播放按钮直接进入全屏，缺少过渡动画

## ADDED Requirements

### Requirement: 明亮配色体系
网站SHALL采用明亮配色体系，核心变量如下：
- 主背景：`#f8f9fc`（柔和白）
- 次背景：`#ffffff`（纯白卡片）
- 表面：`rgba(99, 102, 241, 0.04)`（微紫透明）
- 文字主色：`#1a1a2e`（深靛蓝）
- 文字次色：`#5a5a7a`（中灰紫）
- 文字弱色：`#8a8aa8`（浅灰紫）
- 强调色：`#6366f1`（靛蓝紫，保留）
- 玻璃效果：`rgba(255, 255, 255, 0.7)`（明亮毛玻璃）
- 玻璃边框：`rgba(99, 102, 241, 0.12)`（微紫边框）
- 渐变1：`linear-gradient(135deg, #6366f1, #a855f7)`（保留但增加饱和度）
- 渐变2：`linear-gradient(135deg, #06b6d4, #10b981)`（保留）
- 渐变3：`linear-gradient(135deg, #f59e0b, #ef4444)`（保留）
- 渐变4：`linear-gradient(135deg, #ec4899, #8b5cf6)`（保留）

#### Scenario: 用户打开网站
- **WHEN** 用户访问任一页面
- **THEN** 页面呈现明亮、通透的视觉效果，背景为浅色系，文字为深色系

### Requirement: AIGC艺术化视觉语言
网站SHALL采用AIGC风格的艺术化视觉语言：
- 卡片采用「渐变光晕边框」效果：卡片边缘有流动的渐变光效
- 标题采用「渐变文字+光效扫过」动画
- 视频卡片悬停时展示「光效扩散」动画
- 背景添加「流动渐变网格」装饰元素
- 技能标签采用「胶囊渐变」样式
- 时间线节点采用「脉冲发光」效果
- 整体视觉传达「AI创意、数字艺术、未来感」的品牌调性

#### Scenario: 用户浏览首页
- **WHEN** 用户浏览首页各个区域
- **THEN** 每个区域都呈现出独特的AIGC艺术化视觉效果，包括渐变光晕、流动动画、创意排版

### Requirement: 视频加载优化
网站SHALL优化视频加载机制：
- IntersectionObserver预加载策略从 `metadata` 升级为 `auto`（对可见视频）
- 播放前检测 `video.readyState >= 3`（HAVE_FUTURE_DATA），未就绪时显示加载动画
- 添加视频加载loading指示器（脉冲圆环动画）
- 播放失败时显示错误提示而非静默失败
- 视频元素添加 `playsinline` 属性以优化移动端体验
- 对非可见视频保持 `preload="none"` 节省带宽

#### Scenario: 用户hover视频卡片
- **WHEN** 用户将鼠标悬停在视频卡片上
- **THEN** 如果视频已缓冲完成则立即播放；如果未就绪则显示加载动画，就绪后自动播放

#### Scenario: 视频加载失败
- **WHEN** 视频因网络或其他原因加载失败
- **THEN** 显示友好的错误提示信息

### Requirement: 全站风格统一
所有页面（index.html、video-collection.html、contact.html）SHALL采用统一的明亮配色体系和AIGC艺术化视觉语言。

#### Scenario: 用户在页面间导航
- **WHEN** 用户从首页导航到视频合集或联系页面
- **THEN** 页面风格保持一致，无视觉跳变

## MODIFIED Requirements

### Requirement: 导航栏设计
导航栏SHALL采用明亮毛玻璃效果：
- 默认背景：`rgba(248, 249, 252, 0.8)`
- 滚动背景：`rgba(248, 249, 252, 0.95)`
- 底部边框：`rgba(99, 102, 241, 0.1)`
- Logo保留渐变色
- 导航链接文字为深色

### Requirement: Hero区域
Hero区域SHALL适配明亮主题：
- Orb动画配色调整为明亮系（降低饱和度、提高亮度）
- 标题渐变色适配明亮背景
- 副标题和描述文字为深色
- CTA按钮保留渐变色但增加明亮阴影

### Requirement: 视频卡片设计
视频卡片SHALL采用明亮主题+艺术化设计：
- 卡片背景：`rgba(255, 255, 255, 0.8)`
- 卡片边框：渐变光晕效果
- 悬停效果：光效扩散+轻微上浮
- 视频描述区域默认半透明展示，hover展开完整内容

### Requirement: 时间线设计
时间线SHALL适配明亮主题：
- 时间线竖线：明亮渐变
- 节点圆点：脉冲发光效果
- 卡片背景：明亮毛玻璃
- 卡片遮罩层适配明亮背景

## REMOVED Requirements

### Requirement: 深色主题配色
**Reason**: 用户明确要求从暗淡风格切换为明亮风格
**Migration**: 所有深色CSS变量替换为明亮系变量
